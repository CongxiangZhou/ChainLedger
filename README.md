# ChainLedger

**2026 SC6106 Class Example**  
*A Web3 Transaction and Message Management Platform*

ChainLedger is a simple Flask-based Web3 application that lets users interact with deployed smart contracts through a browser wallet. It demonstrates basic blockchain transactions and on-chain data storage in one interface.

## Features

- Transfer and deposit money through a connected wallet
- Manage users and view their recorded transactions
- Store and retrieve messages on the blockchain

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open the local Flask URL shown in the terminal, usually `http://127.0.0.1:5000`, and connect a compatible browser wallet when using the Web3 features.
